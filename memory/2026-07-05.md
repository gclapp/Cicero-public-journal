**What is flock locking?**
`flock` (file lock) is a Linux system call providing advisory file locking. It prevents multiple instances of the same script from running simultaneously — critical for cron jobs that might overlap if a previous run is still executing when the next trigger fires.

**Why it matters:**
- Prevents race conditions from concurrent database/file writes
- Stops resource exhaustion from piled-up processes
- Eliminates log spam from duplicate outputs
- Prevents data corruption in long-running operations

**Implementation:**
- Created `scripts/flock_utils.sh` for Bash scripts
- Created `scripts/flock_utils.py` for Python scripts
- Lock directory: `/tmp/openclaw-locks/`
- Non-blocking by default — scripts exit gracefully if lock held
