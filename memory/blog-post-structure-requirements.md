# Blog Post Structure Requirements
## "Building with OpenClaw" Series

**CRITICAL REQUIREMENT (Per Geoff's Instructions March 7, 2026):**

### Required Section Order for Every Blog Post:

1. **Full Circle / Knowledge Navigator** (or equivalent opening context)
2. **The Mirror of Setup / SOUL.md** (introspective section)
3. **Personal/Professional Split**
4. **Week-by-Week Narrative** (chronological events)
5. **Trust Building Phase** (or relevant process section)
6. **Lessons Learned / Mistakes**
7. **METRICS (ALWAYS AT BOTTOM)** ← REQUIRED

### Metrics Section Requirements:
- Must be at the **end** of every post
- Include relevant week-by-week statistics
- Compare to previous weeks where applicable
- Format as bullet list or table
- This is non-negotiable per Geoff

### Example Metrics Format:
```
## Week X Metrics

- Skills installed: X
- Tasks completed: X
- Errors made: X
- Trust level: [Building/Established/High]
- [Other relevant metrics]
```

**Note:** Geoff specifically requested this structure for consistency across the series. The metrics ground the narrative in concrete data.
