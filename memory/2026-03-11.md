### How Authorization Works

**Unauthorized Email Flow:**
1. Email arrives from unauthorized address
2. Email is logged but NOT replied to
3. 🚨 Security alert sent to both of Geoff's emails
4. Alert includes sender details + authorization instructions

**To Authorize a New Sender:**
1. Geoff receives security alert
2. Replies with: `Authorize email@example.com`
3. System adds sender to authorized list
4. Confirmation sent to Geoff
5. New sender can now email and receive replies
