# Active Systems - Behavior Patterns

## Restaurant-Friend Matching System
**Status:** ACTIVE | **Created:** March 1, 2026

### Trigger
When Geoff mentions any restaurant (visited, planning to visit, or considering).

### Action
1. Ask: "Who else of your friends might like this place?"
2. Capture: Friend name + match reasoning
3. Store: In places-people-tracker.md
4. Use: Future suggestions when friend hasn't been seen in a while

### Data Captured
- Restaurant name, location, vibe
- Friend name
- Why it's a match (interests, location, occasion)
- Type: Group vs. date vs. business

### Example Use
**Geoff:** "Went to Bestia last night..."
**Me:** "How was it? Who else of your friends might like that spot?"
**Geoff:** "Actually, Adam would love it — casual but great food, downtown"
**[I log: Bestia → Adam Dole (casual but quality, downtown, group-friendly)]**

**3 weeks later:**
**Me:** "You haven't seen Adam in a while — want to check out Bestia? You mentioned he'd love the casual vibe."

### Purpose
Turn restaurant experiences into planned friend connections using data.
