# Weight Loss Program 2026

**Goal:** Lose 20 lbs in 10-12 weeks  
**Start Date:** February 28, 2026  
**Approach:** High-protein, lower-carb + Strategic exercise + Whoop integration

## Plan Overview

### Timeline
- **Weeks 1-4:** Aggressive phase (2 lbs/week) - 8 lbs
- **Weeks 5-8:** Steady phase (1.5 lbs/week) - 6 lbs  
- **Weeks 9-12:** Maintenance transition (1 lb/week) - 6 lbs
- **Total:** 20 lbs

### Nutrition Strategy
- **Calories:** 1,800-2,000/day
- **Protein:** 150-180g/day (30-35%)
- **Carbs:** 20-25% (complex carbs only)
- **Fats:** 40-45% (healthy fats)

**Geoff-Approved Foods:**
- Steak, chicken, fish, eggs, Greek yogurt
- All vegetables, especially greens
- Avocado, nuts, olive oil
- Berries, apples
- Pizza/burgers: Weekends only, moderation

### Exercise Plan (5-6 days/week)
- **Mon/Wed/Fri:** Strength training (45 min)
- **Tue:** Cardio/walk (30-40 min)
- **Thu:** Active recovery/yoga (30 min)
- **Sat:** Fun activity/hike (60+ min)
- **Sun:** Rest (Whoop recovery focus)

### App Integration Stack
1. **Whoop** (already have) - Recovery, strain, sleep tracking
2. **Lose It!** (already using) - Food logging, connects to Whoop
3. **Todoist** - Daily/weekly reminders and check-ins
4. **Apple Health** - Central hub connecting all apps

### Reminder System

- 7 AM: Weigh-in, check Whoop recovery

**Weekly (Sunday):**
