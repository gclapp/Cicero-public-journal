## Weather Fix

**Time:** 7:34 PM UTC  
**Issue:** Weather showing "Data unavailable" in health checks

### Problem
`system_health_check.py` was calling `openclaw weather "Los Angeles"` but that CLI command doesn't exist — the weather skill only provides documentation.

### Solution
Updated script to use `curl wttr.in` directly:
```python
result = subprocess.run(
    ['curl', '-s', 'wttr.in/Los+Angeles?format=%l:+%c+%t+%h+%w'],
    capture_output=True,
    text=True,
    timeout=15
)
```

### Result
Weather now displays: `los angeles: ☀️ +26°C 47% ↑5km/h`
