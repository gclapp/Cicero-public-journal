# From Dashboard to Settings

## Looking at Your Screenshot

You're on: substack.com/dashboard

## Find Settings

Look at the **TOP RIGHT** of your screen:

1. **Do you see your profile picture?** Click it
2. **Do you see "Settings"?** Click it
3. **Do you see a gear icon ⚙️?** Click it

## If None of Those Work

Look at the **TOP LEFT** or **TOP CENTER**:
- Do you see "Geoff Clapp"? Try clicking it
- Do you see a hamburger menu (three lines)? Click it

## Try This URL

Type this directly in your address bar:
```
substack.com/settings/publication
```

Or:
```
substack.com/publish/settings
```

## What You Should See

A page with:
- Publication name: [text field with "Geoff Clapp"]
- Subdomain: [text field with "geoffclapp"]
- Description: [text area]

## If You Still Can't Find It

Your publication might be using your personal profile name. In that case:

**Option 1:** Create a new publication at:
```
substack.com/dashboard?type=writer
```

**Option 2:** Contact Substack support to rename
