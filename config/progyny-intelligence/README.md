# Progyny Intelligence Knowledge Base

## Overview
Persistent storage for all Progyny-related intelligence, mentions, and trends.
Updated daily, summarized weekly.

## Data Structure
- `mentions/`: Individual mention records (JSON)
- `trends.json`: Aggregated trend analysis
- `weekly-summaries/`: Weekly summary reports
- `sources-index.json`: Master index of all sources with links

## Categories Tracked
- Stock/Financial (earnings, analyst ratings, price movements)
- Product/Service (new offerings, features, partnerships)
- Executive/Leadership (Pete Anevski, team changes)
- Client/Employer (new clients, renewals, expansions)
- Competitive Positioning (vs Maven, Carrot, Kindbody)
- Market Sentiment (Reddit, news, social)
- Regulatory/Policy (legislation affecting fertility benefits)
