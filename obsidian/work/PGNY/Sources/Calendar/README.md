# Calendar Sources

This folder stores processed work calendar snapshots for PGNY briefs.

Raw calendar exports should remain in the capture layer:

```text
/home/ubuntu/Obsidian/OpenAI Work/00 Cicero Inbox/Calendar/Work/
```

If using the local assembled vault, raw exports may also be dropped here:

```text
/home/ubuntu/Obsidian/OpenClaw/00 Inbox/Calendar/Work/
```

## Snapshot Format

Use one note per relevant week or date range:

```text
YYYY-MM-DD_to_YYYY-MM-DD - Work Calendar Snapshot.md
```

Each snapshot should summarize:

- Date range
- High-priority meetings
- Prep needs
- Follow-up-heavy meetings
- Travel or schedule constraints
- People appearing repeatedly
- Open questions for Geoff

## Priority Rules

Prioritize:

- Executive team meetings
- Board meetings
- CEO meetings
- Product strategy meetings
- Customer or partner meetings
- Hiring or org design conversations
- Travel
- Long blocks that constrain follow-up time

Deprioritize:

- Routine holds
- Tentative placeholders
- Duplicate invites
- Events with no title or unclear ownership
