# Wednesday - Midweek Execution Update

Use this brief to reset the week while there is still time to act.

## Purpose

Answer: what has happened, what changed, what is still left, and what needs Geoff's attention next?

## Primary Inputs

- Meetings and calendar events from Monday-Wednesday
- Remaining calendar for Wednesday-Friday
- Current week's Sunday brief
- Action notes created or updated this week
- Decisions and blockers
- Relevant notes from `Meetings/`, `Projects/`, and `shared-inbox/Inbox/`

## Output Shape

- What happened so far
- What changed
- What is left to do
- What is blocked
- Who needs a reply or decision
- What Geoff should handle next

## Storage

Generated Wednesday briefs should live in this folder with a date prefix:

```text
YYYY-MM-DD - Wednesday - Midweek Execution Update.md
```
