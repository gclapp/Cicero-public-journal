## 📚 12-WEEK CURRICULUM

### PHASE 1: PYTHON FUNDAMENTALS (Weeks 1-2)
**Goal:** Translate Java thinking to Python

**Week 1: Syntax & Basics**
- Variables, types, operators
- Lists, dicts, sets (vs Java Arrays, HashMaps)
- Control flow (if/else, loops)
- Functions & scope
- File I/O

**Week 2: Object-Oriented Python**
- Classes & inheritance
- `self` vs `this`
- Properties & decorators
- Magic methods (`__init__`, `__str__`, etc.)
- Modules & packages

**Project:** Build a "Task Manager" CLI tool (like Todoist CLI)
- CRUD operations on tasks
- File persistence (JSON)
- Command-line interface

**Resources:**
- "Python for Java Developers" (YouTube/Articles)
- Official Python tutorial (docs.python.org)
- Practice: LeetCode easy problems in Python

---

### PHASE 2: PYTHONIC PATTERNS (Weeks 3-4)
**Goal:** Write idiomatic Python, not "Java in Python"

**Week 3: Python Idioms**
- List/dict comprehensions
- Generators & iterators
- Context managers (`with` statements)
- Lambda & functional programming
- `*args` and `**kwargs`

**Week 4: Advanced Python**
- Decorators (function & class)
- Metaclasses
- Type hints (Python 3.9+)
- Error handling (exceptions vs Java try-catch)
- Virtual environments & pip

**Project:** Build a "Web Scraper Agent"
- Scrape watch listings from Bob's Watches
- Use `requests` + `BeautifulSoup`
- Save to JSON/CSV
- Handle errors gracefully

**Resources:**
- "Fluent Python" by Luciano Ramalho (Chapters 1-4)
- Real Python tutorials
- Python standard library docs

---

### PHASE 3: AGENT FOUNDATIONS (Weeks 5-6)
**Goal:** Understand how agents work

**Week 5: Working with APIs**
- HTTP requests (`requests` library)
- JSON parsing
- Authentication (API keys, OAuth)
- Rate limiting & error handling
- Webhooks

**Week 6: LLM Integration**
- OpenAI API basics
- Prompt engineering
- Token management
- Streaming responses
- Function calling / tools

**Project:** Build a "Simple Chat Agent"
- CLI that talks to GPT-4
- Maintains conversation history
- Can execute simple commands
- Saves conversations to file

**Resources:**
- OpenAI API documentation
- "Building LLM Apps" tutorials
- My existing agent code (you can study it)

---

### PHASE 4: AGENT ARCHITECTURE (Weeks 7-8)
**Goal:** Build multi-tool agents

**Week 7: Tool Use & Function Calling**
- Defining tools for LLMs
- JSON schemas
- Tool selection logic
- Chaining tool calls

**Week 8: Agent Patterns**
- ReAct pattern (Reasoning + Acting)
- Planning & execution
- Memory & context management
- Error recovery & retries

**Project:** Build a "Email Agent"
- Reads emails via IMAP
- Summarizes with LLM
- Can draft replies
- Integrates with your Gmail

**Resources:**
- LangChain docs (for patterns, not necessarily the library)
- "AI Agent Design Patterns" articles
- Study my watch-hunt agent code

---

### PHASE 5: PRODUCTION AGENTS (Weeks 9-10)
**Goal:** Build deployable, robust agents

**Week 9: Async & Concurrency**
- `async`/`await` (vs Java Futures)
- `asyncio` library
- Concurrent API calls
- Background tasks

**Week 10: Data & Persistence**
- SQLite for agent memory
- Redis for caching
- Environment variables & secrets
- Logging & monitoring

**Project:** Build a "Competitive Intelligence Agent"
- Monitors competitor news
- Scrapes websites
- Generates reports
- Emails you summaries
- **This is a real agent you'll use!**

---

### PHASE 6: ADVANCED AGENTS (Weeks 11-12)
**Goal:** Build your own agent framework

**Week 11: Multi-Agent Systems**
- Agent communication
- Task delegation
- Orchestration patterns
- Shared memory/context

**Week 12: Deployment & Infrastructure**
- Docker containers
- Cron jobs / scheduling
- Cloud deployment (AWS/GCP basics)
- Monitoring & alerts

**Final Project:** Build Your Own Agent System
- Multiple specialized agents
- Shared memory/state
- Web dashboard (optional)
- Deployed and running

1. **Python 3.11+** (latest stable)

```bash

mkdir ~/agent-projects
cd ~/agent-projects

# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install base packages
pip install openai requests beautifulsoup4 python-dotenv
```

- OpenAI API key (for LLM access)
- SerpAPI or similar (for search)
- Various service APIs (as needed)
